# SynthScan

> **SynthScan** — we scan for synthetic content. Text. Images. Code. Anything AI-made.

![status](https://img.shields.io/badge/status-alpha-yellow)
![license](https://img.shields.io/badge/license-Apache--2.0-blue)

SynthScan is an **open-source, self-hostable AI-content authenticity scanner**. It
detects whether a piece of content was written by a human or generated by AI
(text today; image and code detection are on the roadmap). It is built to be
**open, free, private, and fair** — the code is auditable, your text never has to
leave your machine, and a score is *a signal to investigate, never a verdict to
punish*.

Read the full philosophy in [POSITIONING_MANIFESTO.md](POSITIONING_MANIFESTO.md).

---

## Why SynthScan?

- **Open source & auditable.** The entire detection pipeline is public.
- **Self-hostable.** Run it on your laptop, a school's server, or a $5/mo VPS.
  Your text stays in your hands — ideal for FERPA/GDPR-sensitive environments.
- **Zero-shot by default.** Production detection uses Binoculars (no per-model
  retraining), with a lightweight statistical backend for dev/offline use.
- **Fair by design.** Outputs are probabilities with per-segment highlighting,
  not accusations.

## Install

Core (runs everywhere, no heavy ML dependencies):

```bash
pip install -e .
```

Production detection (adds PyTorch + Binoculars — large download):

```bash
pip install -e ".[ml]"
```

API server:

```bash
pip install -e ".[api]"
```

---

## Quick Start (CLI)

Scan text directly:

```bash
synthscan scan "It is crucial to emphasize the importance of the landscape." --backend heuristic
```

Scan from a file:

```bash
synthscan scan --file essay.txt
```

Machine-readable output:

```bash
synthscan scan "Some text here." --json
```

List available detection backends:

```bash
synthscan list-backends
```

---

## Quick Start (API server)

```bash
synthscan serve --host 0.0.0.0 --port 8000
```

Then:

```bash
curl -X POST http://localhost:8000/scan/text \
  -H "Content-Type: application/json" \
  -d '{"text": "It is crucial to emphasize the importance of the landscape."}'
```

Health check:

```bash
curl http://localhost:8000/health
```

## Backends

| Backend | Deps | Notes |
|---------|------|-------|
| `heuristic` | none | Lightweight statistical baseline for dev/tests/demos. **Not** production-accurate. |
| `binoculars` | `synthscan[ml]` | Zero-shot deep-learning detector (ICML 2024). The production path. |

Register your own backend by implementing the `Detector` protocol and calling
`register_backend(...)` — perfect for community models, image detection, etc.
